Agentic AI analyst

Ask a question in plain language. The agent plans, retrieves context from dbt docs (RAG), writes SQL against the gold tables and explains the result. This demo uses scripted answers; the production build connects to an LLM.

Ask about categories, returns, customers, ratings, revenue trend or at-risk segments.

RAG over your data docs

dbt model descriptions, column definitions and data-quality rules are embedded into a vector index, so the agent answers with the right metric definition and cites its source.

1. Embed
Chunk dbt docs and schema files, then store vectors in pgvector on PostgreSQL.
2. Retrieve
Hybrid keyword and vector search finds the top matching definitions.
3. Answer
The agent grounds its SQL and explanation in those definitions and links the source model.

Run it anywhere with Docker

One command starts Spark, Airflow, PostgreSQL and the dashboard.

services:
  spark:    { image: bitnami/spark:3.5, ports: ["8080:8080"] }
  airflow:  { image: apache/airflow:2.9, depends_on: [postgres] }
  postgres: { image: pgvector/pgvector:pg16 }
  dbt:      { build: ./dbt, command: dbt build }
  agent:    { build: ./agent, env_file: .env }
  web:      { build: ./web, ports: ["3000:3000"] }

$ docker compose up --build

    End-to-end architecture

    Sources flow left to right. Every stage is orchestrated by Airflow and monitored for freshness and quality.

    SourcesOrders, customers, products, reviews (CSV, API, CDC)
    IngestSpark Structured Streaming and batch jobs
    Delta LakeBronze, Silver, Gold with ACID and time travel
    Transformdbt models, tests and lineage docs
    ServePostgreSQL marts and pgvector index
    ConsumePower BI / Looker, AI analyst, CNN tagger

    Gold data model

    A star schema keeps dashboards fast and metric definitions consistent.

    TableGrainKey columns
    fct_ordersOne row per order lineorder_id, customer_id, product_id, net_revenue, discount, status
    dim_customersOne row per customercustomer_id, segment, first_order_date, clv
    dim_productsOne row per productproduct_id, category, brand, price, cnn_category
    fct_reviewsOne row per reviewreview_id, product_id, rating, sentiment
    mart_daily_salesOne row per day and categorydate, category, revenue, orders, return_rate

    Platform capabilities

    Data quality gates
    dbt tests and Great Expectations-style checks block bad batches before Silver.
    Time travel and audits
    Query any table as of a past version to reproduce a report.
    Incremental and CDC loads
    Delta MERGE keeps tables current without full reloads.
    Column-level lineage
    Trace any dashboard number back to its raw source.
    Observability
    Freshness, volume and failure alerts from Airflow to Slack or email.
    Access control
    Role-based access and PII masking on customer fields.
    Cost-aware compute
    Partitioning, Z-ordering and file compaction cut query time and spend.
    Sentiment on reviews
    Review text is scored and joined to products for return analysis.
