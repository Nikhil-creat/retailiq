# RetailIQ: Lakehouse Analytics Platform for E-commerce Data

Designed and Developed by **NIKHIL CHARY SRIRAMOJU**
GitHub: https://github.com/Nikhil-creat | Email: sriramojunikhil66@gmail.com

Showcase site for an end-to-end lakehouse (Spark, Delta Lake, dbt, Airflow, PostgreSQL, Power BI / Looker) with an agentic AI analyst, RAG and CNN product tagging, shipped with Docker.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server 8000` and visit http://localhost:8000.

## Deploy on GitHub Pages
Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.

## Features
Working in-browser demo: generated order data, Bronze/Silver/Gold pipeline with quality checks, filterable dashboard, RFM customer segments, agent with TF-IDF RAG retrieval and SQL, convolution vision lab, CSV export, light/dark theme, responsive layout.
